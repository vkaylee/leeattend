## Endpoint Scope and Row Arithmetic

- **Total Protected Endpoints in Matrix**: `403 - 8 = 395` unique rows in `auth-permission-matrix.csv`.

## Source Evidence Inventory

1. **JWT Issuance, Claims, and Expiry**:
   - `apiserver/src/services/auth_service.rs:12-18,46-95`: Standard JWT claims with HMAC-SHA256 (`sub` as user UUID, `iat`, `exp`). Access token lifetime is 15 minutes (`:188`). Refresh session lifetime is 7 days (`:135-143`).
   - `apiserver/src/services/auth_service.rs:147-224`: Refresh rotation generates fresh token pair; token reuse detection immediately revokes all user sessions in Redis.
2. **JWT Extraction, Validation, and Revocation**:
   - `apiserver/src/lib.rs:180-255`: Extraction precedence is `Authorization: Bearer <token>`, followed by `access_token` cookie, followed by `access_token` query parameter.
   - `apiserver/src/lib.rs:122-155,214-219`: Redis blacklist checks for token signature (`jwt:revoked:{sig}`) and timestamp revocation (`user:revoked_at:{user_id}`). Redis failures fail open to preserve database availability.
3. **Workspace Context Extraction and Caching**:
   - `apiserver/src/handlers/common.rs:79-111,198-252`: `MemberContext` resolves `ws_id` path parameter first, falling back to `X-Workspace-Id` header. Validates active membership and caches permissions/roles in Redis with 1-hour TTL.
4. **Permission and Role Enforcement**:
   - `apiserver/src/handlers/common.rs:131-193`: `require_permission`, `require_scoped_permission` (enforcing department scope), and `require_any_scoped_permission`. Missing permission returns `403 Forbidden`.
   - `apiserver/src/handlers/system_auth.rs:44-79,117-161`: `SystemContext` extracts user roles from cache/DB. `require_role` and `require_any_role` reject non-platform users with `403 Forbidden`. `SystemRoleType::PlatformAdmin` and `SystemRoleType::Support` are defined in `apiserver/src/models/enums.rs:624-630`.
5. **Rate Limiting Middleware**:
   - `apiserver/src/lib.rs:359-363`; `apiserver/src/mw/rate_limit.rs:42-108,168-223`: Global rate limiter enforces `120 req / 60s` for reads and `30 req / 60s` for writes. Redis sliding-window with Moka local memory fallback.
   - `apiserver/src/routes/auth.rs:13-29`: Dedicated route limiter on `/login` and `/register` (`10 req / 60s`).
6. **Audit Event Emission Callsites**:
   - `apiserver/src/services/audit_service.rs:20-68`: `AuditHelper::log` persists structured audit records asynchronously.
   - Handler callsites: `dashboard_metrics.rs:92-111`, `dashboard_overtime_breakdown.rs:160-179`, `workspaces/permissions.rs:98-108,162-172`, `workspaces/members.rs:129-139,195-205,260-270`, `workspaces/roles.rs:111-121,171-181`.
   - Service callsites: `custom_field_service.rs:122-132,175-185,209-219,464-525`, `location_service.rs:67-77,118-128,173-183`, `employer_service.rs:67-77,122-132,177-187`.

## Fixed Compatibility Rules

| Category | Compatibility Rule for Go Migration | Source Verification |
|---|---|---|
| **JWT Claims & Expiry** | HMAC-SHA256 with `sub` (UUID), `iat` (seconds), `exp` (15m). Validate signature with secret; reject expired tokens with 401. | `apiserver/src/services/auth_service.rs:12-18,72-95,188` |
| **Refresh Rotation** | Session lifespan 7 days. Single-use refresh token rotation; token reuse detects compromised credentials and revokes all active sessions for the user. | `apiserver/src/services/auth_service.rs:135-143,147-224` |
| **Revocation Checks** | Query Redis `jwt:revoked:{sig}` and `user:revoked_at:{user_id}`. If `iat < revoked_at`, reject with 401. Preserve fail-open behavior if Redis is offline. | `apiserver/src/lib.rs:122-155,214-219` |
| **Workspace Context** | Extract workspace UUID from URL path parameter `{ws_id}` first, then `X-Workspace-Id` header. Non-member access yields 403. Cache member permissions with 1h TTL. | `apiserver/src/handlers/common.rs:79-111,198-252` |
| **Permission Evaluation** | Check `Permission::*` against caller active roles/permissions. Return 403 on missing permission. Scoped checks enforce managed department match. | `apiserver/src/handlers/common.rs:131-193` |
| **System Authorization** | `SystemContext` extraction alone does NOT grant access. Handler must explicitly invoke `ctx.require_role` or `ctx.require_any_role`. | `apiserver/src/handlers/system_auth.rs:64-79,157-159` |
| **Default Deny** | Do not invent missing guards. Where Rust codebase lacks explicit guard, record `NONE EVIDENCED` and enforce default-deny decision before Go cutover. | `auth-permission-matrix.csv` (157 unguarded rows) |
| **Service Identity** | User-facing endpoints do NOT support service tokens. Only `GET /api/v1/ws` authenticates machine identity via `x-agent-id` + `x-token` against `agents` table. | `apiserver/src/handlers/agents.rs:66-97` |
| **Rate Limiting** | Global sliding-window rate limit: 120 reads/min, 30 writes/min per user/IP. Strict auth route limit: 10/min. Bypass for `/health` and `/health/ready`. | `apiserver/src/mw/rate_limit.rs:42-108,168-223` |
| **Audit Trail** | Emit exact audit action strings on state modifications. Persistence must fail open so audit DB errors do not abort user transactions. | `apiserver/src/services/audit_service.rs:20-68` |
