# Migration Decision & Escalation Log

## 1. Governance Rules
- Every architectural divergence, schema ambiguity, or contract mismatch must be logged here before changing code.
- Escalation rule: If a Rust behavior is ambiguous or requires contract change, stop implementation, log here, and request lead engineer decision.
- Permitted decisions: `Approved`, `Rejected`, `Escalated`.
