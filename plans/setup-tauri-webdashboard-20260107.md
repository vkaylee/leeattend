# Implementation Plan: Tauri Setup for WebDashboard (Static Export)

**Task:** Convert the Next.js `webdashboard` into a Windows Desktop Application using Tauri.

## Approach
- **Static Export:** Next.js will be configured with `output: 'export'` to generate static HTML/CSS/JS files that Tauri can bundle.
- **Tauri Integration:** Initialize Tauri in the `webdashboard` directory and configure it to point to the `out/` folder generated by Next.js.

## Steps

### 1. Configure Next.js for Static Export (10 min)
- **Modify:** `webdashboard/next.config.ts`
- **Action:** Change `output: 'standalone'` to `output: 'export'`.
- **Note:** Static export disables some features like SSR (Server-side rendering) and API routes within Next.js. Since we have a separate Rust `apiserver`, this is acceptable.

### 2. Update package.json scripts (5 min)
- **Modify:** `webdashboard/package.json`
- **Add:**
  ```json
  "scripts": {
    "tauri": "tauri",
    "export": "next build"
  }
  ```

### 3. Initialize Tauri (15 min)
- **Run:** `npm install -D @tauri-apps/cli`
- **Run:** `npx tauri init`
- **Configuration during init:**
    - App name: `leeattend-dashboard`
    - Window title: `LeeAttend Management Dashboard`
    - Frontend dist path: `../out` (Path to Next.js export)
    - Dev server URL: `http://localhost:3000`

### 4. Configure Tauri for Next.js (10 min)
- **Modify:** `webdashboard/src-tauri/tauri.conf.json`
- **Action:** Ensure `beforeDevCommand` and `beforeBuildCommand` are set correctly to automate the build flow.
  ```json
  "build": {
    "beforeDevCommand": "npm run dev",
    "beforeBuildCommand": "npm run export",
    "distDir": "../out",
    "devPath": "http://localhost:3000"
  }
  ```

### 5. Verification (20 min)
- **Dev mode:** `npm run tauri dev`
- **Build mode:** `npm run tauri build` (Generates `.exe` or `.msi`)

## Timeline
| Phase | Duration |
|-------|----------|
| Next.js Config | 15 min |
| Tauri Init | 20 min |
| Testing | 25 min |
| **Total** | **1 hour** |

## Rollback Plan
1. Revert `next.config.ts` to `output: 'standalone'`.
2. Delete `webdashboard/src-tauri` directory.
3. Uninstall `@tauri-apps/cli`.

## Security Checklist
- [ ] Ensure `apiserver` CORS allows the Tauri internal origin (usually `tauri://localhost` or `http://localhost`).
- [ ] Use `tauri.conf.json` to restrict capabilities (allow-list only necessary APIs).
- [ ] Disable devtools in production build.
